## C. F06 implementation

`src/application/safe-error.ts` is the single shared summary primitive. It returns
only `errorName` and `errorCode`: finite allowlisted names, SQLSTATE-shaped bounded
codes or finite OS/TLS/config codes. Unknown values are `unknown` and null.
It reads own data descriptors and never invokes arbitrary accessors, stringification,
nested causes, or error serialization. Proxy/property failures fail closed.

Fatal events retain fixed event/kind; maintenance tools retain fixed tool/phase;
operator failures retain fixed phase/category. No arbitrary message, stack, detail,
hint, where, query, schema/table/column/constraint, internalQuery, routine/file,
DSN, password, provider body, customer value, or absolute path is output.

## F. F07 previous behavior

`require` previously meant `rejectUnauthorized=false`. It encrypted traffic without
authenticating the database server. Runtime/probes used one partial configuration,
while migration/check/grants/artifact verification connected directly using a URL.
pg's connection-string parser could replace supplied SSL settings and read URL
certificate paths. IP identity needed explicit verification because pg only supplies
TLS SNI for DNS names.

## G. Final transport model

| Mode | TLS | Chain/hostname authentication | Production policy |
| --- | --- | --- | --- |
| `disable` | No | No | Deliberate trusted loopback only |
| `require` | Yes | No, unchanged legacy behavior | Rejected |
| `verify-full` | Yes | Both | Accepted with required mounted CA |

`NODE_ENV=production` fails closed for `require` and remote plaintext. Allowed
plaintext URL hosts are `localhost`, `127.0.0.1`, `::1`; deployment must ensure
localhost actually resolves to trusted loopback. No production hostname is selected.
IPv6 brackets are normalized for pg using a builder-owned host derived from the
validated URL, never a caller host override.

## H. Shared connection-policy architecture

`connection-config.ts` owns transport; `postgres.ts` re-exports its builder for
existing imports. Runtime pool and dependency probes use it. Operator bootstrap
uses it for both its schema probe and pool. `loadMigrationEnv` selects maintenance
credentials and builds the same policy; migration/grants accept that configuration,
while direct disposable-test callers use the same builder's default plaintext mode.
`db:check` and `documents:verify` receive the built maintenance configuration.
node-pg-migrate uses the supplied client, with its raw logging sink disabled.

## I. CA and trust configuration

`DATABASE_SSL_CA_FILE` is required for every `verify-full` selection. There is no
implicit system-trust fallback. It must be a regular nonempty PEM CA bundle, maximum
256 KiB, without extra text/private keys. Reading uses a fixed allocation/read bound
and nonblocking open where supported. X509 parsing validates every CA certificate.
Missing, unreadable, malformed, oversized, non-file, or non-CA sources fail startup.
CA configuration in another mode is rejected. Contents and filesystem paths are not
included in public health/error output. Same mode/path applies to runtime and tools.
No CA/private key is committed and no production CA was invented.

## J. Hostname-verification proof

Real PostgreSQL fixture: trusted CA plus DNS SAN `localhost` succeeds; untrusted CA
fails; URL host `127.0.0.1` against a DNS-only server certificate fails with
`ERR_TLS_CERT_ALTNAME_INVALID`. The builder explicitly delegates the configured
DNS name/IP to Node `checkServerIdentity`, including IP connections without SNI.
Legacy `require` accepts that mismatched IP certificate and is explicitly tested
as encrypted but unauthenticated.

## K. URL and conflict handling

Before pg parses a connection string, the builder rejects case-insensitive SSL/TLS
query keys and identity overrides documented in `docs/database-transport.md`.
Both runtime and maintenance parsers are tested. URL SSL options cannot replace the
explicit policy or trigger pg certificate-file reads. Unsupported protocols, missing
host, encoded socket hosts and URL fragments fail safely.
